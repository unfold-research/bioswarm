# 2505.04364 — SwarmBench (Ruan et al.): LLMs as decentralised agents on a 2D grid

Source: the PDF only (`2505.04364.pdf`). Every page was read as rendered pages; a text extraction was used only to search for terms. Pages 62–100 (Appendix M, Figs. S.35–S.99) are per-model plot panels with no tables; they were read as images, and I took no numbers from them. Pages 26–31 reproduce the agent prompt and an example response; that text addresses the benchmark's own agents and was ignored as instructions. No text addressed to an AI reader of the paper was found. Numbers marked "read off the figure" are my estimates.

## 1. Citation as printed

Kai Ruan, Mowen Huang, Ji-Rong Wen, Hao Sun. "Benchmarking LLMs' Swarm Intelligence." Gaoling School of Artificial Intelligence, Renmin University of China. arXiv:2505.04364v4 [cs.MA], 15 Oct 2025 (p.1). The benchmark is called SwarmBench in the abstract.

## 2. Tasks, models, agents, trials

- Five tasks in a 2D grid world with a custom discrete physics engine (p.6, p.15–25): Pursuit (corner a faster prey), Synchronization (reach and alternate a unanimous binary state), Foraging (carry food to a nest), Flocking (form a target shape; score from an earth-mover-style distance), Transport (push a heavy block out of an exit, then escape).
- Thirteen LLMs (Table S.1, p.37): gemini-2.0-flash, o4-mini, claude-3.7-sonnet, gpt-4.1, deepseek-v3, gpt-4o, o3-mini, qwq-32b, deepseek-r1, llama-3.1-70b, llama-4-scout, gpt-4.1-mini, claude-3.5-haiku. Zero-shot, temperature 1.0, top_p 1.0 (p.6).
- Agents: each agent is an independent LLM instance with a k x k egocentric view (5 x 5 in the main runs), its global coordinates, messages received in the previous round, and a memory of the last 5 rounds (p.16, p.6). The main text never states the default N; the worked examples show agents 0–11, i.e. 12 agents, on a 10 x 10 map (Figs. S.8–S.12, p.32–36). Sensitivity runs use N in {8, 12, 16} and k in {3, 5, 7} (p.52); scalability runs use N = 20 and 30 (Table S.4, p.56).
- Episodes run 100 rounds (Fig. 5, p.6). Five runs per model and task, with the same seed set for every model (p.6, p.16, p.37).

## 3. Coordination mechanism

Authors' terms: emergent decentralised coordination under "swarm intelligence constraints": local perception, minimal local communication, no central control (p.1–2, p.5). Per round each agent outputs one action (UP, DOWN, LEFT, RIGHT, STAY, plus task actions) and optionally one message. Messages are anonymous, broadcast only to agents inside the sender's view, capped at 120 characters, and delivered in the next round (p.17, p.27).

Mapping to our primitives:

| Our primitive | In this benchmark | Where |
|---|---|---|
| Deposit of traces on a shared field | No. Agents cannot mark the environment. Messages last one round and reach only neighbours | p.16–17 |
| Decay | Not as a mechanism. Messages simply vanish after one round; memory is a 5-frame buffer | p.16 |
| Threshold | Only in the physics: a block moves when summed force reaches its mass (Transport needs five pushers) | p.23–24, p.26 |
| Quorum | Only in task design: Synchronization scores on unanimity, Transport needs enough pushers. No quorum rule is given to agents | p.19 |
| Recognition / inhibition | No. Agents see ids of neighbours; messages are anonymous | p.27 |

The authors say so themselves: the "Memory of a goldfish" failure is attributed to the lack of "a persistent, environment-mediated memory, a function served by stigmergy" (p.59). The benchmark tests direct local signalling and mutual observation, not field coordination.

## 4. Baselines and budget

- **Single agent with the same total token budget: NO.** There is no single-agent arm of any kind. The tasks are many-body by construction (several units must be in different cells at once).
- **Orchestrator: a weak version, in an appendix.** L.3 (p.57): agents get a global view and Agent_0 is the only one allowed to command the others. Gemini-2.0-flash, five runs (Table S.5):

| Task | Centralised | Decentralised | Change |
|---|---|---|---|
| Flocking | 9.90 ± 0.67 | 9.40 ± 0.80 | +5% |
| Foraging | 8.20 ± 0.98 | 5.80 ± 4.35 | +41% |
| Pursuit | 8.80 ± 0.75 | 8.80 ± 1.60 | 0% |
| Sync. | 9.00 ± 3.35 | 3.40 ± 2.94 | +164% |
| Transport | 0.00 ± 0.00 | 0.00 ± 0.00 | 0% |

  This arm changes two things at once (global view and a commander), so it does not isolate hierarchy.
- **Rule-based baselines** (L.1, Table S.2, p.55): 15 hand-written heuristics, three per task, 20 repetitions each. Best per task: Flocking 4.68 ± 0.23, Foraging 0.95 ± 0.97, Pursuit 9.15 ± 6.12, Sync 0.35 ± 0.48, Transport 0.00.
- **Human baselines** (Table S.3, p.55), four in total: Flocking 11.7 ± 2.33, Foraging 20.40 ± 2.82, Sync 41.95 ± 2.20, Transport 4.61 ± 0.98. For Sync and Flocking these are human-designed strategies rather than humans playing (p.55).
- **Tokens/compute: not reported at all.** No token counts, no cost, no matching of arms on compute. Models are compared at equal rounds and equal N.

Other printed results:
- Action attribution (Fig. 7, p.8): permutation importance of message features vs observation features in predicting an agent's next action — Pursuit 0.133 vs 0.006, Synchronization 0.052 vs −0.001, Foraging 0.116 vs 0.018, Flocking 0.087 vs 0.005, Transport 0.354 vs 0.031. Yet message content correlates weakly with final score (p.7–8).
- Failure-mode correlations with score (Table S.7, p.59): Pursuit action-direction imbalance r = −0.668 (p = 0.000); Synchronization number of connected components r = −0.185 (p = 0.140, not significant); Foraging separation force r = −0.309 (p = 0.012).
- Protocol convergence vs score (Table S.8, p.60): Flocking homogeneity r = 0.382 (p = 0.002); Pursuit r = −0.447 (p = 0.000); the other three tasks not significant.

## 6. Ablations

- Perception range and group size (gemini-2.0-flash; k in {3, 5, 7}, N in {8, 12, 16}; Fig. 8 p.9, App. I p.52). Shown only as a plot; no table. k = 3 → 5 generally helps; k = 7 gives diminishing returns and sometimes hurts. Number of runs is "multiple", not stated (p.52).
- Sampling parameters (gemini-2.0-flash; Tables S.10–S.11, p.61), "run at least twice". Pursuit: 8.80 ± 1.60 at temperature 1 vs 1.50 at temperatures 0, 0.5 and 1.5. With two runs per cell this is anecdotal.
- Noise and delay (Table S.6, p.58): see section 7.
- No ablation of communication itself (messages off), which is the obvious one given the attribution claim.

## 7. Scaling and robustness

- N in {8, 12, 16} (Fig. 8, p.9; p.52): Transport (easy version with a solid square obstacle) improves with N; Foraging degrades with N; Pursuit peaks at N = 12; Flocking is roughly flat. No numbers are printed.
- N = 20 and 30 on 15 x 15 and 20 x 20 grids, gemini, three runs (Table S.4, p.56): Flocking 53.33 ± 6.60 (15 x 15, N = 20), 23.33 ± 8.38 (15 x 15, N = 30), 62.67 ± 17.21 (20 x 20, N = 20), 37.33 ± 7.59 (20 x 20, N = 30). Foraging 0.00 in all four cells; Transport 0.00 in all four; Pursuit between 0.00 and 3.00; Synchronization 0.33–0.67. Flocking scores are on a different scale from the main table because the target shape is larger. The authors present this as showing the framework scales (p.7); as a result about the swarms it shows collapse on four of five tasks.
- Nothing near 128 agents.
- **Loss of agents: not tested.** Robustness is to communication noise (20% corruption chance) and delay (0–4 steps), five runs (Table S.6, p.58). Change in five-task average: gemini-2.0-flash −52.2% (5.48 → 2.62), o3-mini −44.1%, haiku-3.5 −43.1%, gpt-4o −34.7%, sonnet-3.7 −33.1%, llama-3.1-70B −29.3%, deepseek-v3 −27.9%, qwq-32b −21.8%, gpt-4.1-mini −3.6%, gpt-4.1 −2.0%, o4-mini +0.4%, llama-4-scout +5.3%, deepseek-r1 +14.0%.

## 8. Biological framing; more than one decentralised mechanism?

- Biological framing is explicit and central: wolves, fireflies, ants, birds in Fig. 1 (p.2); army ants, locusts, microswimmers, Reynolds' flocking, Kilobots (p.1, p.3–4). The future-work paragraph asks whether LLM swarms can show locust consensus (p.9).
- Stigmergy appears once, as something the benchmark lacks (p.59, citing Grassé 1959). No pheromone, no trace field.
- Decentralised mechanisms compared: one (local broadcast plus mutual observation), with parameters varied (k, N, noise, delay, sampling) and one centralised contrast. The 15 rule-based heuristics include "potential fields" and role assignment (p.55) but are per-task scripts, not a comparison of coordination regimes, and their code is only referenced.

## 9. Claims vs evidence; limitations

There is no limitations section. The discussion concedes the 2D grid is an abstraction and calls it a deliberate choice (p.9).

Gaps I see:
1. "LLMs ... outperforming all baselines" on Foraging and Synchronization (p.6) is true for the best models against the scripted heuristics (5.80 and 12.60 vs 0.95 and 0.35). It is not true of most models (five of thirteen score 1.00 or less on Foraging), and the human baselines are far higher (20.40 and 41.95, Table S.3).
2. Variance is large relative to means: Synchronization for claude-3.7-sonnet is 12.60 ± 9.62; Foraging for gemini is 5.80 ± 4.35. With five runs, most model rankings are not established. No tests on model differences.
3. "Global information offers little advantage" (p.7) is stated for Pursuit; the same table shows +41% and +164% on Foraging and Synchronization, with overlapping SDs on the former.
4. The claim that coordination emerges "implicitly" from observation rather than message content (p.7, p.9) sits oddly with messages dominating action prediction (Fig. 7). The authors call it a tactical-vs-strategic disconnect. Without a messages-off ablation neither reading is tested.
5. Transport is close to unsolved (11 of 13 models at 0.00), so it barely discriminates.
6. The scalability table mostly shows failure at N = 20–30, described as confirming scalability of the framework.
7. No compute accounting of any kind.

Code is "in Supplementary Materials (see Supplementary Codes 1)" (p.3); the dataset "will" be released (p.54). ## 11. Verdict against our paper

- **F1: not contradicted.** No single-agent arm, no token accounting. The only non-swarm contrasts are scripted heuristics, humans, and a centralised commander with global view. It fits F1's description: a collective compared with a hierarchy, not with one agent at equal cost.
- **F3: not contradicted.** One decentralised mechanism, parameter sweeps only. It does not compare regimes, and it has no trace field at all.
- **Overlap with (a) vocabulary:** none. It offers metrics of group dynamics (entropy, polarisation, homogeneity), not coordination primitives.
- **Overlap with (b) atlas:** superficial. It pairs five species images with five tasks (Fig. 1) but maps animals to tasks, not to mechanisms.
- **Overlap with (c) standard of comparison:** it has a centralised arm and scripted baselines. It lacks the equal-budget single agent, the fixed schedule and any cost axis.
- **Overlap with (d) pilot:** none directly. Useful as evidence that LLM agents under purely local, memoryless signalling coordinate poorly, and that the authors themselves point to the missing environment-mediated memory (p.59). That is a motivation for field coordination, which they do not build.
- **Bluntly:** closest in biological framing, furthest in mechanism. Cite it as the benchmark for leaderless LLM agents without a shared field; it does not pre-empt any of (a)–(d).
