# 2610.16120 — ScaleMAS (Qi et al.)

Source: the PDF only (`2610.16120.pdf`). Every page was read as rendered pages; a text extraction was used only to search for terms. No text addressed to an AI reader and no embedded instructions were found. Numbers marked "read off the figure" are my estimates from a plot, not printed values.

## 2. Tasks, models, agents, trials

- Four benchmarks (p.5, p.19):
  - BrowseComp-Plus (deep research), first 100 questions, answers graded by an LLM judge (Qwen3.5-flash) (p.19).
  - FATE (Lean 4 theorem proving): FATE-M first 100 problems, FATE-H all 100 (p.19).
  - SWE-bench Verified on mini-SWE-agent, first 100 instances (p.19).
  - Contradiction Audit, built by the authors: 16 documentation corpora, 20 injected contradictions each over 40 snippets, padded with distractors to 40n snippets (levels x4 = 160 snippets, x8 = 320) (p.5, p.15–16). Contradictions are injected and judged by GPT-5.6 (p.5, p.15).
- Models: Qwen3.5-9B on all four benchmarks; Claude-5-Sonnet on all but SWE-bench Verified. The stronger model gets the harder splits (FATE-H, Contradiction Audit x8) (p.6).
- Group sizes: 1, 2, 4, 8, 16 with Qwen3.5-9B (Fig. 1, p.1); 1, 2, 4, 8 with Claude-5-Sonnet (Fig. 4, p.6); up to 128 on two benchmarks with Qwen3.5-9B (Fig. 6, p.7).
- Trials: Table 6 lists "Random seed 0, 1, 2" (p.19), but the paper never says that reported numbers are means over three seeds, and no table gives a standard deviation. Figures 1 and 4 show a shaded band around the ScaleMAS line that no caption explains. The only stated interval is "95% bootstrap CIs" in Fig. 8b (p.8).
- Temperature 1.0, generation limit 16,384 tokens per call (Table 6, p.19).

## 3. Coordination mechanism

Authors' terms: an "agent substrate" = a datastore of messages, three operations, and deterministic rules (p.3, footnote 1 p.2). All N agents run the same harness under the same prompt; nobody holds a role, sends a message to another agent, or assigns work; agents run asynchronously (p.3).

- **Shared datastore.** Append-only sequence of messages m = (u, a, r, R): sub-task, artifact, short rationale, references. A message is "never edited or deleted" (p.3). Sub-task plus artifact are capped at 256 or 1,024 tokens depending on the benchmark; at most 32 references per message (p.3, Table 6 p.19). References form a DAG (p.3).
- **Operations.** `publish`, `search(q)` (returns the k highest-ranked messages), `visit(m1..mj)` (fetch by address). k = 8 for both search and visit (Table 6, p.19). Author and weight are never shown to readers (p.4).
- **Write rule.** A message is rejected unless every reference exists and the rationale names every reference and says what it contributed (p.4).
- **Ranking by citation.** Each message has a citation weight s in [0,1), starting at s0 = 0. When a new message cites m, s_m moves a fraction α toward 1: s_m ← s_m + α(1 − s_m). Search score = s_m + normalised BM25 relevance (Eq. 1, p.4). Only messages with positive BM25 score are ranked, so weight reorders relevant messages but cannot surface an unrelated one (p.4). α = 0.3 (Table 6, p.19). The authors relate this to PageRank (p.4).
- **Decay: yes.** "at every step of the group all weights decay, s_m ← γ s_m" (p.4), γ = 0.98 (Table 6, p.19). What decays is the ranking weight only; the message text persists for ever.
- **Persistence.** Messages outlive their producers; a newcomer catches up by searching (p.3). The datastore lives for one task only and is discarded with it (p.14).

Mapping to our five primitives:

| Our primitive | In ScaleMAS | Where |
|---|---|---|
| Deposit of traces on a shared field | Yes: `publish` to an append-only shared store | p.3 |
| Reinforcement (part of deposit in our scheme) | Yes: citation weight rises with each citing message | p.4 |
| Decay | Yes, of the weight (γ = 0.98 per group step), not of the content | p.4, p.19 |
| Threshold | Only as a retrieval cut-off: top-k = 8 and "positive retrieval score". No response threshold on signal strength | p.4 |
| Quorum | None. Weight is graded; no decision needs a minimum number of endorsers | — |
| Recognition / inhibition | None. Author identity is hidden; there is no negative mark or inhibitory signal | p.4 |

So ScaleMAS is one fixed configuration: deposit + reinforcement + decay + bounded read. In our vocabulary it is a single "regime". It is stigmergy in everything but name.

## 4. Baselines and budget

Baselines (p.5–6): Parallel ReAct (N agents, no communication), Multi-Agent Debate (all-to-all), AOrchestra (central coordinator that decides how many sub-agents to launch; one point per plot), DeLM (blackboard-style shared context).

- **Orchestrator arm: yes** — AOrchestra (p.6).
- **Single agent given the same total budget as the collective: NO.** There are N = 1 points (ScaleMAS with one agent, ReAct with one agent), but each agent has a fixed per-agent cap (300 / 250 / 100 / 300 actions, Table 6 p.19). No arm gives one agent N times the actions or tokens of the group. The introduction itself cites work showing groups can underperform "a single agent given the same inference budget" (p.1) and then does not run that comparison.
- **Tokens per arm.** Reported only as the x-axis of Figs. 1, 4 and 10: "Mean input + output tokens per example" on a log scale. There is no table of tokens per arm. A few values appear in prose (p.6, p.8).
- **Are arms matched?** Not by design. Arms share prompts, per-benchmark action limit, tools and harness (p.6, p.16), and then spend whatever they spend. "Matched compute" means reading across curves at a similar x-value, with different N per method.
- **How "lower inference compute" is measured.** Sum of input and output tokens per example, averaged (Fig. 1 axis, p.1). The paper does not say whether cached tokens are discounted, does not report dollars, wall-clock or number of calls per arm, and does not count the cost of the datastore/BM25 index.
- **Metric caveat that matters for us.** On the three third-party benchmarks the score is Pass@N: the group is correct if any of the N agents is correct (p.16). This is an oracle over N answers, not a committed group answer. The authors call answer selection "orthogonal" (p.16). Any single-agent comparison would be against best-of-N.

## 5. Main results as printed

Qwen3.5-9B, 1 → 16 agents (p.6):
- BrowseComp-Plus 38.1% → 65.3%.
- FATE-M 24.0% → 56.0%.
- Contradiction Audit x4 4.1% → 29.4%.
- SWE-bench Verified "levels off after eight agents" (p.6); Fig. 1 shows the 16-agent point slightly below the 8-agent point (read off the figure).

Claude-5-Sonnet (p.6): Contradiction Audit x8 10.6% (1 agent) → 57.5% (8 agents).

Compute comparisons in prose (p.6):
- At about 20M tokens per example on BrowseComp-Plus: 8 ScaleMAS agents 60.0% vs 16 DeLM agents 26.0%.
- SWE-bench Verified: 4 ScaleMAS agents reach 80.0%, same as 8 ReAct agents, with 15.3M vs 28.3M tokens.
- Claude-5-Sonnet, about 3.5M tokens on BrowseComp-Plus: 8 ScaleMAS 79.8% vs 8 MAD 73.0% vs 4 ReAct 72.0%.
- MAD on BrowseComp-Plus (Qwen): 5.6M tokens (2 agents) → 48.5M (16 agents), accuracy stays 28%–32%.
- MAD and DeLM never exceed 7% on Contradiction Audit at any size (p.6).

Turns (Fig. 5, p.7): mean turns per agent fall from 304 (1 agent) to 205 (8) on BrowseComp-Plus with Qwen, and from 150 to 94 with Claude-5-Sonnet. Eight Qwen agents take about 5.4 times the total turns of one agent. Claude on BrowseComp-Plus: 80 task-tool calls per example in a group of eight vs 134 alone. Contradiction Audit x8: tool calls 131 → 98, datastore searches 12 → 65.

Analysis (p.7–8):
- Fraction of messages on the evidence chain of a correct answer: 29% in the least-cited fifth, 85% in the most-cited fifth, 49% overall, over 413 examples (Fig. 8a). The authors concede this measure reflects connectivity as well as relevance (p.7).
- Messages naming a gold document get 0.98 citations from other agents vs 0.49 for other sources (Fig. 8b, 95% bootstrap CIs).
- Share of correct answers resting on a gold document the submitter never opened: 9% (2 agents) → 24% (8 agents); 8% at 8 agents under the stricter criterion (Fig. 9).

Variance: none in tables. No significance test anywhere in the paper.

## 6. Ablations

- **Citation weight in ranking** (Fig. 10, p.8–9; Qwen3.5-9B, group sizes 1–8; three conditions: standard, BM25 only, random order among matching messages). At N = 8: BrowseComp-Plus 60.0% vs 40.8%; Contradiction Audit x4 23.1% vs 9.7%. On FATE-M the two "stay within four points up to N = 4" and separate at N = 8 (49.0% vs 42.0%), where BM25 alone reads twice the tokens (5.7M vs 2.7M). Random ranking does about as well as BM25 alone at N = 8 on all three benchmarks. Sample: the same first-100-question subsets (16 corpora for Contradiction Audit). No test, no interval. SWE-bench Verified and Claude-5-Sonnet are not in this ablation.
- The ablation removes the whole weight term. There is **no separate ablation of decay (γ) or of the reinforcement step (α)**, and no sweep of k.
- **Communication** (Table 2, p.9; four Qwen3.5-9B agents):

| | BrowseComp-Plus | FATE-M | SWE-bench Verified | Contradiction Audit x4 |
|---|---|---|---|---|
| ScaleMAS | 55.1 | 42.0 | 80.0 | 10.0 |
| private substrate (each agent reads only its own messages) | 46.8 | 38.0 | 71.6 | 6.6 |
| w/o substrate (independent ReAct) | 38.0 | 36.0 | 68.0 | 8.1 |

  The authors read this as: reading one another accounts for "about half or more" of the gain over independent sampling (p.8–9). Note the other half comes from an agent writing notes to itself.

## 7. Scaling and robustness

- **Up to 128 agents** (Fig. 6, p.7): Qwen3.5-9B only, on FATE-M and Contradiction Audit x4 only, against DeLM and MAD only (no ReAct, no AOrchestra, no token axis). FATE-M: most of the gain is reached by N = 16, then it "levels off just below 60%"; MAD peaks at N = 32 and declines. Contradiction Audit x4: improves at every doubling to 50.9% at N = 128; DeLM and MAD never exceed 7%.
- **One permanently failing agent** (Fig. 11, p.8–9): Contradiction Audit x4, Qwen3.5-9B. One extra agent that returns errors at every step, healthy count held fixed. With seven healthy agents both conditions reach 19.4%. DeLM falls below 1% with one failed member. This is the "N agents with one failed ≈ N − 1 healthy" claim (p.3). One benchmark, one model.
- **Dropout** (Fig. 7, p.7–8): each agent is absent from each step independently with probability p in {0, 0.2, 0.4, 0.6, 0.8}; N = 1, 2, 4, 8; FATE-M with Qwen3.5-9B and Contradiction Audit x8 with Claude-5-Sonnet; AOrchestra as reference. At p = 0.8 on FATE-M: 22.0% with eight agents vs 2.0% with one. AOrchestra loses more than half its score at p = 0.2. Agents return after dropping; this is intermittent absence, not permanent loss.

## 8. Biological framing; more than one decentralised mechanism?

- No biological framing. The words stigmergy, pheromone, ant and swarm (in the collective sense) do not occur. The stated lineage is blackboard systems (Newell, Nii, Erman) and the Web / PageRank (p.2, p.4, p.14).
- The agent prompt does use trail language: a reference "merges your work into an existing trail" (p.20).
- Decentralised mechanisms compared: ScaleMAS, DeLM (shared context), MAD (all-to-all), parallel ReAct (none). These are different systems from different papers, not variants of one field mechanism. Within the substrate, only the ranking rule is varied (standard / BM25 / random).

## 9. Claims vs evidence; limitations

Stated limitations (p.9): scaled only to 128 agents "due to limited compute"; substrate used only at inference time. That is all.

Gaps I see:
1. "Lower inference compute" rests on curves with a log x-axis and no token table; the comparison is between methods at different N, never against one agent with the group's budget.
2. Pass@N is an oracle metric (p.16). Gains with N partly reflect more draws. Parallel ReAct also rises with N under this metric (p.6). The honest coordination effect is the gap to ReAct at equal N, not the rise from N = 1.
3. Part of the gain is not coordination: ScaleMAS beats ReAct already at N = 1 (p.6), and the private-substrate row of Table 2 recovers a large share of the gain on BrowseComp-Plus (46.8 of the 38.0 → 55.1 rise).
4. On Contradiction Audit x4 at N = 4, the private substrate (6.6) is worse than no substrate (8.1) (Table 2). The text reports this pair without comment on direction.
5. The 128-agent claim covers two of four benchmarks, one model, two baselines.
6. The conclusion says ScaleMAS improves "up to sixteen on three of the four" benchmarks with Qwen (p.9); the abstract says it "continues to scale up to 128 agents" (p.1), which holds for the two tested.
7. No variance, no tests, three seeds listed but their use unstated.
8. Fig. 4 (Claude-5-Sonnet, FATE-H): DeLM's highest point looks above ScaleMAS's highest point, at far more tokens (read off the figure). "Outperforms at matched compute" holds; "outperforms" without the qualifier does not obviously hold there.
9. Contradiction Audit is built and filtered with GPT-5.6 and scored with a relaxed metric: extra reported pairs are not penalised (p.5, p.16). A system that reports many pairs is not punished for false positives.
10. The eight case studies (p.20–29) are selected, "preferring tasks on which a single agent with the same backbone fails" (p.20).

No repository, no data link and no licence are stated anywhere in the PDF. The only URL to code is the third-party smolagents library (footnote 2, p.5). The paper does not say whether Contradiction Audit will be released.

## 11. Verdict against our paper

- **F1 (collectives are compared with conversation or hierarchy, not with one agent at the same total cost): not contradicted; supported.** ScaleMAS has no full-budget single-agent arm. Its N = 1 points have one agent's budget, not the group's (Table 6, p.19; Figs. 1, 4). It even cites the equal-budget problem on p.1 and leaves it untested. It is a clean example for F1.
- **F3 (nobody compares several bio-inspired regimes on one task): not contradicted.** One substrate configuration; the only variation is the ranking rule (Fig. 10). No decay sweep, no quorum, no inhibition.
- **Overlap with (a) vocabulary:** partial and implicit. It implements deposit, reinforcement and decay on a shared store and names none of them in our terms. It has no threshold in our sense, no quorum, no recognition/inhibition, and no notion of regimes as configurations.
- **Overlap with (b) atlas:** none.
- **Overlap with (c) standard of comparison:** it has the orchestrator arm (AOrchestra) and a no-communication arm; it lacks the fixed-schedule arm and the same-total-budget single agent. Token cost is plotted, not tabulated.
- **Overlap with (d) pilot:** it is far larger than our pilot and it does show a reinforcement ablation (citation weight on/off). It does not show where trace-following loses, except incidentally (Table 2, Contradiction Audit private substrate; SWE-bench plateau).
- **Bluntly:** ScaleMAS is the strongest existing evidence that a trace-on-shared-field design with reinforcement and decay beats an orchestrator and debate on real agentic tasks. We must cite it as prior art for the mechanism and must not claim that field coordination with reinforcement and decay is new. What remains ours: the biological vocabulary and atlas, the multi-regime comparison, the equal-total-budget single agent, and the fixed schedule. Our pilot should not be presented as the first test of decay-plus-reinforcement.
