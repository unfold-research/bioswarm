## 2. Tasks, models, settings, trials

The main text (pp.1–8) contains no experiments. Appendix D (pp.20–26) has an "exploratory pre-experiment" (p.20):

- Validation I: three datasets, SRDD, IdeaBench, CommonGen; 30 randomly sampled tasks each; 5 agents; one model, Qwen3-30B-A3B-Instruct-2507; chain topology vs tree topology (p.20, p.21).
- Validation II: a single task, "Navigation Buddy" from SRDD (p.21), in three phases: 3 agents with role diversity (Table 4, p.22); programmer swapped to Qwen3-Coder-30B-A3B-Instruct (p.23); chain extended to 5 agents (p.24).
- No confidence intervals, no seeds, no number of repetitions reported anywhere in Appendix D.

## 3. How budget is matched

- Definition: Φ_S is the single agent's best result "when allocated a total resource budget equivalent to that of the MAS" (p.4).
- The resource unit is left task-dependent: "token throughput, sampling steps, or tool-invocation counts" (p.4); Appendix B.2 repeats "token length, sampling steps, or tool-invocation counts" (p.19).
- The single agent must use "the most capable model base within the MAS" (p.19).
- In the experiments the unit is tokens: the SAS is run with extended CoT "within the same total token budget as the MAS" (p.21); "strict token budget (B_max = 20,000) for both systems", the MAS splitting it across agents and rounds (p.21).

Consequence for us: our standard (one agent holding the same total token budget as the collective) is the same standard this paper proposes and uses. We cannot present it as new. What we can add is fixing the unit to tokens in all cases, where this paper allows steps or tool calls (p.4, p.19), and reporting uncertainty, which Appendix D does not.

## 5. Decentralised / peer-to-peer coordination

- The factor "organizational structure" covers topology in general; the paper says a restrictive topology "may impose bottlenecks" (p.6). No preference for decentralised designs is argued in the main text.
- Appendix A.1 (p.14) classifies biological collectives into three paradigms: decentralized swarm intelligence (no leader, local interactions; army ants, starlings), centralized organization (naked mole-rat, gorilla), hybrid (honeybee). The same three-way split is applied to LLM agents (p.18).
- Stigmergy is named once as an implicit communication protocol: individuals release cues that "modify the environment" (p.14). Quorum is named once, for honeybee nest-site choice (p.14).
- Table 1 (p.15) lists bio-inspired algorithms (ACO, PSO, ABC, Boids, BEECLUST, virtual pheromone, AntNet). All are classical; none is an LLM-agent system.
- Appendix A.3 states that LLM collectives differ from biological ones because natural language is "the core medium of coordination" (p.17). The paper treats language exchange as the defining mechanism, not environment-mediated coordination.
- No decentralised or stigmergic LLM system is tested. The experiments use a chain and a tree (Fig. 6, p.20).

## 6. Taxonomy, collective gain, methodology

Collaboration gain: Γ = Φ_M / Φ_S (Eq. 1, p.4). Φ_M is MAS performance; Φ_S is the best single-agent performance under an equivalent total resource budget (p.4). Γ = 1 is the "theoretical floor for collaboration"; Γ > 1 is read as synergy (p.4). A footnote allows any function f(Φ_M, Φ_S) instead of the ratio (p.4).

Baseline construction by output type (Appendix B.1, p.18):
- Accumulative tasks: sum of independent single-agent instances sharing the budget.
- Coverage tasks: union of problems solved by independent sampling (e.g. self-consistency with k paths) under the budget.
- Single-solution tasks: one agent with the whole budget spent on deeper reflection or extended CoT.

Factor attribution (pp.4–5): fix a budget; build the saturated single-agent baseline; measure the MAS under the same budget; classify each design factor as Class I (Γ > 1 "with statistical significance") or Class II (Γ ≲ 1); add a stability filter requiring a sustained Γ > 1 (p.5). The paper explicitly prefers this binary filter to regression on unverified factors (p.4). Appendix D applies no significance test.

Factor library (Fig. 3, p.6; Table 3, pp.19–20):
- Task context (external): task decomposability, sequential dependency, task clarity (p.5); Table 3 adds task complexity and openness (p.19).
- MAS construction, control level (static): organizational structure, communication mechanism, agent diversity, agent scale (p.6, p.7).
- MAS construction, information level (dynamic): content entropy H_t (Eq. 2, p.7) and evolutionary distance D_t, summed cosine distance of agent state vectors between rounds (Eq. 3, p.7).
- Single-agent enhancements such as memory and tool use are deliberately excluded (p.19).

Overlap with our five primitives (trace deposit on a shared field, decay, threshold, quorum, recognition/inhibition):

- No overlap in the proposed vocabulary. "Communication mechanism" is defined as a range from natural language to latent representations (p.6; Fig. 3 p.6), with pruning, entropy compression, token-efficient training and latent working memory as the listed strategies (Table 3, p.20). A shared environment written to and read by agents is not a factor.
- Decay, threshold (in our sense), recognition and inhibition do not appear. "Threshold" appears only for Γ = 1 and for an agent-scale limit (p.3, p.4).
- Stigmergy, pheromone and quorum appear only in the biological background (pp.14–15), not in the factor library.
- Their unit of analysis is a factor (a design variable); ours is a primitive (a mechanism) and a regime (a configuration of primitives). Our primitives would sit inside their "communication mechanism" and "organizational structure" factors as values those factors currently do not include.
- The two information-level metrics (content entropy, evolutionary distance) are diagnostics, not mechanisms. They could be computed on our runs.

## 8. Stated limitations

There is no limitations section. Section 5, "Alternative Views" (p.8), lists three objections and answers each: operational cost of the framework, holism vs reductionism, and correlation vs causation. Hedges elsewhere: the baseline and resource definitions are "task-dependent" (p.4); Appendix D is an "exploratory pre-experiment" and "preliminarily illustrates" (p.20, p.26); a drop in entropy does not imply solution quality (p.7).

Unstated weaknesses I see: Γ depends on how hard the single-agent baseline is tuned, and "best achievable" is not operationalised beyond "extended CoT"; a ratio is unstable when Φ_S is small; one model family; no variance estimates.

## 10. What our introduction can safely write

Safe: "Fan et al. argue that task-level metrics conflate gains from collaboration with gains from a larger computational budget, and propose a collaboration gain Γ, the ratio of multi-agent performance to that of a single agent given an equivalent total resource budget" (p.1, p.3, p.4). Safe: "their factor library organises the design space into task context, control-level presets (organizational structure, communication mechanism, agent diversity, agent scale) and information-level dynamics (content entropy, evolutionary distance)" (pp.5–7, Fig. 3 p.6). Safe for positioning: "that library treats communication as a spectrum from natural language to latent embeddings; coordination through traces left in a shared environment appears only in its biological background" (p.6, p.14). Our baseline should be stated as adopting their standard with the unit fixed to tokens, since they permit tokens, sampling steps or tool calls (p.4, p.19). Do not cite Γ = 1.26, 1.85 or 0.63 as findings: they come from one task without error bars (pp.23–25).
