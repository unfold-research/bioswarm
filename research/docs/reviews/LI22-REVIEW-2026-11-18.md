## What a skeptic would say

The study answers nothing about pheromone decay. The control refreshes its traces every wave, and the tasks end before any trace can age. A real test needs one of these:
- traces that are written once, with the caller not re-prompted;
- a delayed helper owner, for example LI13-style member loss so the helper misses waves after the trace is written;
- or harder directed checks that stay open for several waves.

It should also register a manipulation check: the number of trace reads blocked by evaporation must be greater than 0 before any verdict is read. Until then, report LI22 as "manipulation not engaged".
