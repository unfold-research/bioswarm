## Bottom line

The verdicts are computed correctly. However, the control LI24 promised (equal act rounds) held only at k80. There the primary is 5–0 and inconclusive, and every remaining manager failure is a symmetric collision. Before LI24 can count as separating "slower" from "worse", it needs these changes:

1. Set thinking effort low or off for the manager, or raise `managerMax`.
2. Keep partial assignments from truncated plans.
3. End manager cases on act rounds, not on wave 13.
4. Pair the comparison with LI27's tie-break arms.
