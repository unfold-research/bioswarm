# LI31 review: emergent symmetry breaking in the Colony (claim / nopeer / market, k=40, 8 seeds)

**Reviewer:** Claude Opus 5.5 (`claude-opus-5-5`), independent and read-only. This reviewer is in the Claude family, so the rule asking for a non-Claude reviewer still has to be met by another review.

| Severity | Finding | Response |
|---|---|---|
| High | **The primary metric mostly counts the first implementation, not adaptation.** In 313 of 525 "simultaneous" events (claim 102/142, nopeer 106/194, market 105/189), one side of the pair was still the initial stub before the window. That is the first write of the module, not two sides reacting to each other. | — |
| High | **Function-level attribution cannot be done from telemetry.** `edit`/`write` inputs store only `{path, edits, chars}` and the written-file sha. Old/new text is not recorded, so no event can be tied to the encoder or decoder function itself. I aligned edit shas to timeline hashes (median 85 of ~90 edits consistent per run) and used proxies. Non-initial events: claim 40, nopeer 88, market 84. Of those, events where the pair's two different owner ants edited both files: 29 / 39 / 68. Of those, events where neither module had any other failing check (so the edit plausibly targeted this pair): **2 / 7 / 11**. So roughly 2–5% of counted events are clearly bilateral changes to that pair. | — |
| Medium | **Pairs inside one ant's file range are counted.** 12 of 40 symmetric pairs (seed 31400) have both sides owned by the same ant, so there is no coordination problem. The 26 failed claim `field_trace` calls were mostly "Esse arquivo é seu" on such pairs. The metric should be restricted to pairs that cross ants. | — |
| Medium | **The claim mechanism ran in only half the claim teams.** 62 successful "Eu me adapto…" traces in total: 19, 1, 11, 15, 0, 0, 0, 16 by seed. Seeds 31404–31406 never announced. The announcements were often posted in bursts (six within 12 ms in s31400), before most formats had changed. | — |
| Medium | **"Keep your format when announced to" cannot be confirmed.** In 50 announcements matched to a pair: the owner edited the announced file within 5 min in 45 cases; the announcer edited its own side in 48; both edited in 43. At file level, owners did not visibly hold back, but those edits may have been to other functions. | — |
| Medium | **The parent arbitrated despite being told not to.** Of the parent's successful `ant_send` calls (claim 347, nopeer 330), 127 and 93 name an encode/decode function together with an order to fix it, e.g. "take ownership of failures for your own decoders". This is a tie-break from above that pushes the decoder side to adapt, in both treatment arms. It confounds both H-LI90 and H-LI92. | — |
| Low | **`peer:false` held.** No successful ant-to-ant sends in claim or nopeer. Refused attempts (`antSendFailed`, all "desligadas"): claim 12, nopeer 37. The 3 other `ant_send` errors were bad names ("pai" sent by the parent, "/", "M14-20"). | — |
| Low | **The message cap never bound.** Lowest remaining budget seen: claim 30, nopeer 37, market 85 of 200. No pair-cap refusals. 0 stalls. 1 capped run (nopeer s31402, 60.2 min). Wall time includes the 3-min quiet tail. | — |
| Low | **Token ratio is driven by cache.** Total tokens: claim 383M, nopeer 350M, market 193M (claim ≈1.99× market). About 97% is cached input. Uncached input is 11.7 / 11.1 / 6.8M and output 0.55 / 0.65 / 0.38M, so claim is about 1.7× market on uncached input and 1.45× on output. | — |
| Low | **Market's fresh-input failures mix weak tests with coordination.** Each failing team fails exactly 1 check: <br>• s31403 and s31406: an empty `tags` array is encoded with a "-" sentinel that decodes to `["-"]`. That edge case is not in the 8 test inputs, so this is weak tests. <br>• s31404: `M15.decodeVenue` sniffs between two field orders and misreads single-digit `qty`. That is a leftover of unresolved symmetry hidden by the tests. <br>• s31402: a directed check (`brandTerm` using `siftTitle`). <br>Format-sniffing decoders in final code (rough regex): claim 2, nopeer 6, market 5. | — |
| Low | **Rerun of market s31401.** It ran about 2 h after the original batch, under different fleet load. Its wall time is not strictly comparable. | — |

Exploratory, not preregistered:

**Reading:** the direction favours claim once the first-implementation events are removed. However, the mechanism fired in only 4 of 8 teams, compliance cannot be seen at function level, and the parent's decoder-first directives give a tie-break from above in both arms. No hypothesis is supported. The study's main gap is that the telemetry should log edit old/new text, and the metric should count only non-initial pairs that cross ants.
