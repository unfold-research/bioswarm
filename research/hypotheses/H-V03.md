# Shared board instead of messages

**Status: open.** Proposed engineering hypothesis for the Void programme (`programs/historical/void.md`). No experiment has run.

## Statement
Agents that coordinate through a shared state file with expiry spend far fewer tokens on hand-offs than agents that message each other.

## Variable
coordination channel: direct messages / shared board without expiry / shared board with expiry

## Outcomes
hand-off tokens per task, duplicate work, stale-read errors, acceptance rate

## Prediction
a board with expiry cuts hand-off tokens by at least half with no loss of acceptance; without expiry stale entries cause errors that grow with run length

## Refutation criterion
direct messages match the board on hand-off tokens, or the board loses acceptance

## Strong conventional baseline
a single orchestrator that relays every message

## Basis in this repository
internal OpenBot case (42% of spend in ping-pong message trees), sim-stigmergy, H-07, H-11. These motivate the hypothesis; they do not test it.

## Evaluation scope and limits
Synthetic or licensed tasks in owned or isolated environments, at matched model budget. Cases, seeds, stopping rules and a spending cap are preregistered before any paid run.
