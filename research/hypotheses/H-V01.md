# Context-fit gate

**Status: open.** Proposed engineering hypothesis for the Void programme (`programs/historical/void.md`). No experiment has run.

## Statement
A task that fits one agent context is cheapest with one agent; a swarm pays only above that size.

## Variable
task size relative to one context window: fits / 2–4 packages / repository-scale; arms: single agent, micro-swarm (2–3), partition by package

## Outcomes
cost per accepted task (hidden tests), acceptance rate, wall time

## Prediction
single agent has the lowest cost per accepted task whenever the task fits one context; partition by package wins only on repository-scale tasks

## Refutation criterion
a micro-swarm matches or beats the single agent on cost per accepted task for tasks that fit one context

## Strong conventional baseline
one high-effort agent with the same token budget

## Basis in this repository
LAB-003 (partition helps on large tasks), internal OpenBot case (single agent cheapest on tasks that fit one context), H-03, H-04, H-09. These motivate the hypothesis; they do not test it.

## Evaluation scope and limits
Synthetic or licensed tasks in owned or isolated environments, at matched model budget. Cases, seeds, stopping rules and a spending cap are preregistered before any paid run.
