# An independent verifier behind the gate cuts false success

**Status: refuted in one study.** Hypothesis of the Harness division (`programs/harness.md`). Study 4 (`results/harness-study-4-2026-11/REPORT.md`): neither verifier raised acceptance or cut false success, and their spec-only tests rejected correct code 33% (same model) to 50% (DeepSeek) of the time. The false successes come from one hidden assertion outside the specification (`results/BENCH-ERRATUM-cursor-paginacao.md`), which no spec-derived check can catch. The verifier that won earlier read the sources; a verifier needs a source of truth the implementer lacks.

## Statement
Acceptance tests written by an independent verifier that sees only the specification, enforced as the lead's gate, lower false success on coupled tasks. A verifier of another model family lowers it more than one of the same model.

## Variable
verifier: none / same model, specification only / other model family, specification only

## Outcomes
accepted tasks, false success, verifier test quality (pass on solution, fail on bugs), harm (fewer hidden tests than without a verifier), cost

## Prediction
the other-family verifier accepts at least two more tasks than no verifier and two more than the same-model verifier

## Refutation criterion
neither verifier arm accepts more tasks than no verifier
