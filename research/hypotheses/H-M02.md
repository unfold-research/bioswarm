# Independent sources beat more searchers

**Status: open.** Proposed engineering hypothesis for the Murmur programme (`programs/historical/murmur.md`). No experiment has run.

## Statement
Adding searchers that share a model and a prompt stops finding new primary sources quickly; varying the query strategy finds more than adding copies.

## Variable
swarm composition at equal budget: N identical searchers / N searchers with distinct query strategies / fewer searchers with more effort each

## Outcomes
distinct primary sources found, share of claims supported by two or more independent sources, cost

## Prediction
distinct sources from identical searchers saturate by N = 5; five diverse searchers find more distinct primary sources than fifteen identical ones

## Refutation criterion
identical searchers keep finding distinct sources at the same rate as diverse ones up to N = 15

## Strong conventional baseline
one searcher with the full budget

## Basis in this repository
sim-correlated-vote, LAB-004 (correlation makes voting risky; saturation at scale), H-01, H-15. These motivate the hypothesis; they do not test it.

## Evaluation scope and limits
Synthetic or licensed tasks in owned or isolated environments, at matched model budget. Cases, seeds, stopping rules and a spending cap are preregistered before any paid run.
