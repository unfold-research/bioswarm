# A guest harness keeps its effect inside a host

**Status: partial support.** Hypothesis of the Harness division (`programs/harness.md`). First study: inside OpenBot the rules fired in all nine Unfold runs and the agents kept to them (one message each way, refused reports resent short, marks left unprompted). No workaround was seen in the tool record.

## Statement
Pi with the Unfold extension, running as an agent inside OpenBot, keeps the in-loop effect measured outside it; the host's own instructions, tools and permissions do not cancel it.

## Variable
host: none (bare Pi) / OpenBot

## Outcomes
rule firings per request, agent behaviour after a refusal (mark left, no workaround), cost per accepted task

## Prediction
the same rules fire and are obeyed inside OpenBot as on bare Pi; refused agents leave a mark rather than going around the rule

## Refutation criterion
inside the host the agent routinely reaches the same effect another way (another tool, the shell, a second agent), or the host's setup suppresses the extension's tools
