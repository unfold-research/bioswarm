# Blind reviewer before more workers

**Status: open.** Proposed engineering hypothesis for the Void programme (`programs/historical/void.md`). No experiment has run.

## Statement
An independent reviewer with its own context raises accepted work per dollar more than an extra worker does.

## Variable
second agent role: none / extra worker / reviewer that sees only the diff and the task, not the worker transcript

## Outcomes
accepted tasks per dollar, false success (visible tests pass, hidden tests fail)

## Prediction
the blind reviewer cuts false success by at least a third at equal budget; the extra worker does not

## Refutation criterion
an extra worker matches the reviewer on false success and accepted tasks per dollar

## Strong conventional baseline
a second attempt by the same agent with the same budget (retry)

## Basis in this repository
LAB-001 (blind review may be worth more than coordination; false success in repairs), sim-verifier, H-02, H-13. These motivate the hypothesis; they do not test it.

## Evaluation scope and limits
Synthetic or licensed tasks in owned or isolated environments, at matched model budget. Cases, seeds, stopping rules and a spending cap are preregistered before any paid run.
