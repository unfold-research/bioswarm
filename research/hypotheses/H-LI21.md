# On code that fits, one agent is enough

**Status: preliminary support.** Registered in `tasks/LI7-REAL-CODE-PREREG.md`.

## Result
LI7 (Sonnet 5.5, 5 modules): one agent solved 12 of 12 (11 on its first call) at 28% of the router's output tokens. Not a capacity result: that agent had every specification, which the members had split among them.

## Statement
Below one agent's capacity, a single agent with all specifications solves at least as many cases as the best swarm arm.
