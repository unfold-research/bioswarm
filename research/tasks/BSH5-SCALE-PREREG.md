# BSH5 · Conditional source returns at scale

24 previously untested synthetic logistics instances (seed IDs 1–24), each evaluated with full capacities and with an empty N/C/S capacity record. This is 24 matched problems, 48 condition blocks and 144 strategy runs. Each block uses the same complete volumes, prices and hidden warehouse source for all three arms; input equality is checked at the consumer and in gateway requests. Reuse BSH4 scoring, one source return, up to two proposals, model, flex tier and 8192-token cap. Freeze all instances, balance arm position, run independent blocks concurrently. Each instance has 6–8 indivisible orders and at least one feasible allocation by construction. Never provide a witness or optimum to agents.

Primary results by capacity condition: feasible count and exact-optimum count out of all 24 assigned cases per arm (unobserved transport failures identified separately). Among absent-capacity cases report paired gains/losses in final feasibility and optimality against current stigwait and manager; under complete capacities report unnecessary queries and realized no-query differences. Count both all-case and conditional-on-feasible optimality. Report exact restoration, direct cost, total gateway USD, incremental cost per net extra feasible and optimal case (undefined when nonpositive); feasibility and optima use integer business costs in BRL. API costs are separate from freight. Show observed cost per solution including failed attempts. Treat paired strata separately rather than interpreting a 50% synthetic omission frequency as field prevalence. One independent model draw per configuration. Check every proposed route and enumerate the optimum independently.
